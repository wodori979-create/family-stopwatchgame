# 딱! 타이밍 — 가족 스톱워치 게임

설치 없이 모바일 브라우저에서 플레이하는 한국어 웹 앱입니다. Firebase Hosting + Firestore + Firebase Anonymous Authentication을 사용합니다. Cloud Functions는 필요 없습니다. 설치된 Firebase SDK를 esbuild-wasm으로 브라우저용 번들에 포함합니다.

## 바로 연습하기

이 폴더에서 `npm install` 후 `npm run preview`를 실행하고 http://127.0.0.1:5173 에 접속하세요. Firebase 미연결 상태에서는 연습만 가능하며 기록은 기기 로컬 저장소에 남습니다.

## Firebase 배포

1. Firebase 콘솔에서 프로젝트와 웹 앱을 만들고, Firestore **Standard / Native mode** 데이터베이스를 생성합니다. 테스트 모드 대신 이 프로젝트의 보안 규칙을 배포합니다.
2. Authentication → Sign-in method에서 **Anonymous(익명)** 를 사용 설정합니다.
3. Node.js 환경에서 `npm install -g firebase-tools`, `firebase login`을 실행합니다.
4. 이 폴더에서 `firebase use --add`를 실행하고 프로젝트를 선택합니다.
5. `firebase deploy --only hosting,firestore`를 실행합니다. 인덱스 생성이 끝날 때까지 기다립니다.
6. 출력된 Hosting 주소를 휴대폰으로 엽니다. 제공받은 stopgame-35928 웹 앱 설정이 `public/firebase.js`에 적용되어 있습니다. Hosting 배포 전 브라우저 번들은 자동 빌드됩니다.

Firebase 프로젝트를 변경하려면 `public/firebase.js`의 설정과 `.firebaserc`의 프로젝트 ID를 함께 수정하세요. Firebase 웹 설정은 서버 비밀 키가 아니며 접근 제어는 보안 규칙이 담당합니다. Analytics는 지원되는 브라우저에서 초기화하며 에뮬레이터 모드에서는 실행하지 않습니다.

## 가족 플레이

별명과 가족 이름으로 방을 만들고 가족에게 8자리 코드 또는 링크를 공유하세요. 가족들은 각자 휴대폰으로 참여합니다. 방장이 GO를 누르면 5초 카운트다운 후 자동 시작하고, 각자 STOP으로 기록을 제출합니다. 한 라운드에 한 사람당 한 기록이며 수정·삭제할 수 없습니다. 방장이 기록을 저장하면 한번 더 버튼으로 대기 없이 다음 판을 시작할 수 있습니다. 공동 시작 5초 카운트다운은 유지됩니다. 진행 도중 들어온 사람은 다음 라운드에 참여합니다. 최대 30명입니다.

방장은 나갔다가 같은 기기에서 같은 코드로 재참여할 수 있습니다. 익명 계정이므로 브라우저 데이터를 지우거나 기기를 바꾸면 동일 인원/방장 권한이 복구되지 않습니다. 가족별 계정 복구 및 방장 이전은 아직 지원하지 않습니다.

## 기록과 랭킹 기준

- 가족 화면: 최근 50개 서버 기록 중 현재 라운드를 우선 표시하고 절대 오차로 정렬합니다. 최근 50개보다 오래된 기록도 서버에는 유지됩니다.
- 가족 랭킹: 최근 전체 **500개** 서버 기록에서 2명 이상 참여한 가족을 평균 오차율 `(절대 오차 / 목표 시간) × 100`로 비교합니다. 누적 전체 순위가 아닙니다. 랭킹 탭을 열거나 새로고침하면 갱신됩니다.
- 동점은 같은 오차이며 표시 순서는 기존 조회 순서입니다.
- 랭킹을 위해 별명·가족 이름·경기 기록은 로그인한 모든 참가자에게 공개됩니다. 실명 대신 별명을 사용하세요.

## 시간 측정의 한계

시작은 Firestore가 기록한 서버 생성 시각에서 5초 뒤로 예약합니다. 기기가 만든 미래 시각을 보안 규칙과 비교하지 않습니다. 가족방 입장 및 방장의 GO 요청 전에 본인 참가자 문서의 서버 타임스탬프로 기기 시각을 보정하고, 경과 시간은 `performance.now()`로 측정합니다. 시간은 선택한 난이도 단위로 반올림해 표시·저장하며, 표시된 시간이 목표 시간과 같으면 성공입니다. 예를 들어 목표가 5.0초이면 5.0초로 표시되는 기록이 성공이고 폭죽 및 축하 문구를 보여줍니다. 기기 시계·네트워크 지연에 따라 시작 시점이 다를 수 있으므로 자동 날짜/시간을 켜세요. 앱이 백그라운드로 이동하면 해당 도전은 취소됩니다.

클라이언트 측정 방식이므로 개발 도구로 조작한 기록까지 검증하지는 못합니다. 보안 규칙은 본인 기록, 라운드 참여, 목표 시간, 범위, 단일 제출을 검증합니다. 상금이 걸린 대회 수준의 부정행위 방지에는 서버 판정과 App Check 등의 추가 설계가 필요합니다.

## 솔로 / 가족방 화면

솔로 플레이와 가족방 플레이는 별도 탭입니다. 솔로 시간 설정·기록은 가족방의 시간·기록과 분리됩니다. 가족 라운드가 시작되면 진행 중 솔로 도전은 취소하고 가족 화면으로 이동합니다. 가족 라운드 도중 솔로 GO를 누르면 가족 도전은 취소됩니다. 기록 및 랭킹 오차는 선택한 난이도의 표시 단위로 계산합니다. 가족 랭킹은 같은 난이도끼리 비교합니다.

## 난이도

솔로 및 가족방에서 최상(0.001초), 상(0.01초), 중(0.1초), 하(1초)를 선택합니다. 목표 입력, 스톱워치, 성공 판정 및 기록에 동일한 단위를 적용합니다. 가족방은 방장이 고른 난이도로 참가자 전원이 플레이합니다. 과거 난이도 없는 기록은 중으로 처리합니다. 실제 서버에서 최상 목표 1.123초의 두 참가자 기록 저장과 상 목표 5.12초의 다음 라운드 시작을 확인했습니다.


솔로 및 가족 기록은 목표 시간과의 절대 오차가 작은 순서로 상위 5개를 표시합니다. 가족방에는 초대 링크 아래 기본 게임 링크 복사 버튼이 있습니다. 기록과 가족 랭킹 1~3위는 금·은·동 메달로 표시합니다.

솔로 및 가족 기록은 현재 게임 난이도와 같은 기록만 필터링한 뒤 상위 5개를 표시합니다. 가족 기록은 최근 50개 내 같은 난이도 기록을 비교합니다. 가족방 탭은 가족방 초대(생성·참여·공유)와 가족방 플레이(게임·기록) 두 섹션으로 구성됩니다.

가족방 내부에 가족방초대 / 가족방 플레이 탭 버튼을 나란히 표시합니다. 함께 플레이하기는 게임 탭으로 자동 전환하며 새 가족방 생성 후에는 초대 화면을 유지합니다.

가족방 초대 화면에 현재 참가 인원수와 별명을 표시합니다. 방장 표시를 유지하며 방장만 다른 참가자의 내보내기 버튼을 사용할 수 있습니다. 보안 규칙도 방장에 한해 다른 참가자 문서 삭제를 허용합니다. 제외된 참가자는 실시간으로 게임을 종료하고 참여 화면으로 돌아갑니다. 초대 코드를 다시 입력하면 재참여할 수 있습니다. 실제 서버에서 일반 참가자의 다른 인원 내보내기 차단 및 방장 내보내기 성공을 확인했습니다.

서버 타임스탬프가 null인 경우 재조회하며, 미확정 라운드는 시작하지 않습니다. 회귀 테스트 포함 19개 통과 및 실제 서버 시간 보정 확인 완료.
